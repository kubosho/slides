# 自己受容と自己効力

| 言葉 | この発表での意味 |
| --- | --- |
| 自己受容 | 弱さや失敗も含めて、自分を受け止める |
| 自己効力 | 目標達成に必要な行動を、自分は実行できると考える |

<!--
ここでは、自己受容を「弱さや失敗も含めて自分を受け止めること」、自己効力を「必要な行動を実行できるという見通し」という意味で使います。
たとえば、失敗した自分を否定せずに、次は方法を変えて試せると考えることです。
自己効力は、どんなことでもできるという万能感ではなく、具体的な活動についての信念です。
添付の解説記事では自己肯定感の意味に幅があるので、この発表ではこの二つを分けて考えます。
出典：Bandura (2006), Guide for Constructing Self-Efficacy Scales, pp. 307–309。
https://bpb-us-e1.wpmucdn.com/websites.uta.edu/dist/1/4994/files/2021/07/Guide-for-Constructing-Self-Efficacy-Scales-Bandura2006.pdf
-->

# 日々の仕事で試せること

| 場面 | 持ち帰りたい行動 |
| --- | --- |
| 実装や発表がうまくいかない | 悔しさを認め、改善する点を具体化する |
| 一人では詰まっている | 仲間に相談し、方法を一緒に変える |
| 他人の成果がまぶしい | 自分の現在地から、小さく試せることを選ぶ |

<!--
目安：40秒／累計4:35
この読みを日々の仕事にも持ち帰りたいです。
実装や発表がうまくいかなければ、まず悔しかったという気持ちを認める。そのうえで、次に変える点を具体的に考える。
一人で詰まったら、仲間に相談して、方法を一緒に変えてみる。
他人の大きな成果がまぶしいときも、今の自分が試せる小さな行動を選ぶ。
できたことが少しずつ増える経験は、自己効力を育てる手がかりになります。
これは発表者による仕事への応用であり、作品内の台詞ではありません。
自己効力の形成に関する参考：Bandura (1977), Self-efficacy: Toward a Unifying Theory of Behavioral Change。
https://doi.org/10.1037/0033-295X.84.2.191

# 千歌から学んだこと

**今の自分を受け止めながら、仲間と次の一歩を選べる。**

- 自己受容：普通の自分も、悔しがる自分も受け止める
- 自己効力：具体的な行動を起こし、方法を変えられると考える

今の自分が、誰かと一緒に試せることは何だろう？
