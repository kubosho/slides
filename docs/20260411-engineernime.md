# 前提：東ゆうは有能

- 東西南北を集めてアイドルグループを実現した実行力
- 相手のニーズを汲み取り、懐に入る能力
- 周囲に流されず自分の基準で判断できる自己肯定感

本人の能力自体はかなり高い

# 東ゆうを表す言葉

- 夢をがむしゃらに追った人間
- その行動力は夢を叶える者として正しい
- だが「正しさ」がチームを壊した
- この構造に名前がある

<!--
- 東ゆうは性悪ではない。アイドルになりたい人間としてはまっとう
- オーディションに落ち続け「私一人ではアイドルになれない」と悟った上での行動
- 行動力も策略的思考も、夢を追う人間として間違っていない
- 問題は「正しさ」そのものではなく、それがチームに何をもたらしたか
-->

---

<!-- { "layout": "title-and-texts" } -->

# 「ブリリアントジャーク」

- Netflixのカルチャーメモに由来する言葉
- 有能だが、周りに配慮と敬意を欠いた振る舞いをする人

<!--
原文引用：「いくら有能であっても、同僚に配慮と敬意を持って接することができなければ、Netflixのドリームチームには居場所はありません」
-->

---

<!-- { "layout": "title-and-texts" } -->

# ブリリアントジャークは「状態」

- 誰しもなり得る。あなたも例外ではない
- 正しさの届け方とタイミングがチームの成果を左右

<!--
さて、今日一番主張したいことはこれです。ブリリアントジャークは「あの人はそういう性格だから」ではありません。状態です。環境や状況が変われば、誰でもこの状態に陥り得ます。そしてこの状態から抜け出すこともできます。
-->

# 正論の限界と共通の構造

---

<!-- { "layout": "title-and-texts" } -->

# 正論を振りかざても上手くいかない時がある：東ゆうの場合

- 美嘉に「彼氏がいるなら友達にならなきゃよかった」と言い放つ
- ライブ直前、蘭子に「歌が下手だと感じているなら練習すればいい」と言い放つ

一番努力しているのは認めるが、今それを言っても状況は改善しない

<!--
- 美嘉への発言：翁琉城ボランティア帰りの美嘉の言葉を全否定
- 蘭子への正論：口パクを告知された後に放たれた
- 東西南北内で最も練習しているのは東ゆうなので、蘭子は反論不能。遠藤社長すら苦笑い
-->

---

<!-- { "layout": "title-and-texts" } -->

# 正論を振りかざても上手くいかない時がある：開発現場の場合

障害対応中に、

- 「テストを書いていたなら障害は起きなかった」と言う
- 「そもそもこの設計にしたのが間違いだった」と設計担当の前で言う

正しいが、今それを言っても状況は改善しない

<!--
- 蘭子への正論と同じ構造：相手の判断を名指しで否定、反論しづらい正論
- タイミングと届け方で正論→攻撃に変わる
-->

---

<!-- { "layout": "title-and-texts" } -->

# 疲弊した現場：トラペジウム

- **蘭子**：「アイドルって楽しくないわ」
- **ゆう**：「そんなの、おかしいよ！きれいな服を着て！かわいい髪型をして！たくさん光を浴びて！それがどれだけ幸せなことか分かってる！？」
- **ゆう**：「アイドルって大勢の人たちを笑顔にできるんだよ？」
- **美嘉**：「……近くの人を笑顔にできない人が？」

<!--
- 蘭子「楽しいと思えるのは東さんがアイドルを好きだから」＝正論は普遍的な正しさではなく個人の前提
- 美嘉「近くの人を笑顔にできない人が？」＝大きな正しさを語る前に目の前の人を見ろ
-->

---

<!-- { "layout": "title-and-texts" } -->

# 疲弊した現場：開発現場

- **メンバー**：「この技術スタック、正直つらいです」
- **リード**：「そんなのはおかしい！これだけ整った環境で開発できるのがどれだけ幸せか！」
- **リード**：「多くのユーザーの課題を解決できるんだ！」
- **別のメンバー**：「……チームが疲弊しているのに、良いプロダクトを作れると思いますか？」

<!--
- 構造はトラペジウムとまったく同じ
- 正しさで「つらさ」を上書きするパターン
- 「近くの人を笑顔にできない人が？」＝「チームが疲弊しているのに」
-->

---

<!-- { "layout": "title-and-texts" } -->

# それでも「周りがおかしい」と考えてしまう

- 「近くの人を笑顔にできない人が？」と言われても
- 「チームが疲弊しているのに」と指摘されても
- 周囲のせいにしてしまうのはこの状態の怖さ

<!--
- 美嘉に泣き崩れられても「みんな、おかしいよ！」と思い立ち去った
- 「自分がおかしいかも」ではなく「周りがおかしい」と認知してしまう
- 自分がその状態にあることに気づけない＝最も怖い部分
-->

# 教訓

---

<!-- { "layout": "title-and-texts" } -->

# 正論を正しいタイミングで言えるか？

- 東ゆうはレッスン中に言えたはずのことを本番直前に言った
- リードは設計レビューで承認したはずなのに障害対応中に「設計が間違い」と言う

<!--
- どちらも発言者自身に責任の一端がある
- 言える時に行動せず、最悪のタイミングで言う→正論が「指摘」ではなく「攻撃」になる
-->

正しさを届けるタイミングを間違うとチームが疲弊する

---

<!-- { "layout": "title-and-texts" } -->

# ブリリアントジャーク状態に気づけるか？

気づくタイミング：

- 東ゆうの場合：東西南北の瓦解という決定的な挫折
- 開発現場の場合：メンバー離脱、フィードバック消失


<!--
- 環境が悪化してから気づくことが多い
- 東ゆうは瓦解するまで自分の状態に気づけなかった
- 開発現場でも「誰も意見を言わなくなった」「退職が続いた」で初めて気づくことが多い
-->

---

<!-- { "layout": "title-and-texts" } -->

# ブリリアントジャークから抜け出す：東ゆうの場合

- 「他人のためと言いながら自分のためにやっていた」と自覚した
- 性質を消すのではなく制御することを覚えた

<!--
- 東西南北の瓦解という挫折が自覚のきっかけ
- 「性格が悪い」「往生際が悪い」ことは変わっていない。変わったのは自覚と制御
- 状況の変化（活動実績）も重なってオーディションに受かり、プロとして再出発できた
-->

---

<!-- { "layout": "title-and-texts" } -->

# ブリリアントジャークから抜け出す：開発現場の場合

- 「チームのためと言いながら自分の正しさを証明するためにやっていた」と自覚する
- 品質に厳しい点や納得するまで引き下がらない姿勢を捨てるのではなく、届け方を変える

<!--
- メンバー離脱やフィードバック消失が自覚のきっかけになることが多い
- 「技術に厳しい」「妥協しない」こと自体は変わらなくていい。変わるのは自覚と届け方
- 正論を言える場（設計レビュー、ふりかえり）で言う。障害対応中やリリース直前には言わない
- 東ゆうがプロとして再出発できたように、自覚と制御ができればチームでの信頼も再構築できる
-->
